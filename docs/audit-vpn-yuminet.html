Alertes & recommandations

🇩🇪 DE — RAM critique : 422 MB total, 248 MB utilisé, 157 MB de swap actif. Apache + 5 sites web + Node.js consomment beaucoup. Risque d'OOM si pic de trafic VPN + web simultané.
Recommandation : envisager upgrade RAM ou déplacer certains sites.
🇫🇷 FR — Température CPU : 70°C au repos, pas de ventilation active sur le SmartPi One. En été ou sous charge, risque de throttling à 80°C+.
Recommandation : ajouter un dissipateur ou un ventilateur 5V.
🇺🇸 USA — AEAD Replay warnings : Logs montrent des warnings AEAD Decrypt depuis le client yumi_usa1 (39.144.129.153 = IP chinoise). Causé par la latence élevée et le réordonnancement de paquets UDP à travers le GFW, pas un problème de sécurité.
Recommandation : ajouter replay-window 256 30 dans server.conf si persistant.
🇫🇷 FR — IP dynamique : L'IP publique 92.169.71.224 est une IP résidentielle Free/Orange. Elle peut changer après un reboot du routeur.
Recommandation : DNS dynamique (vpn.yumi-lab.com) + script cron ddclient.
